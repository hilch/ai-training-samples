## AS6 - Projekt 'automat'

Im Programm '125kHzTransp' befindet sich eine Schrittkette in ANSI-C.
Leider wurden hier numerische Werte in der switch/case- Anweisung verwendet.
Das macht den Code schwer lesbar.
Erstelle einen KI- Prompt, der alle numerischen Werte durch 'sprechende' Konstante ersetzt.

## AS6 - Projekt 'fpointerr'

Leider ist dieses Projekt nicht lauffähig, da die ArSim in den SERV wechselt.
Im Logger wird [25316 AR-RTK: EXCEPTION Floating point Fehler](https://help.br-automation.com/#/de/6/diagnostics_support%2Fsys_error%2Ffiles%2Fsyserror_br2000_25316.htm) als Fehlerursache angegeben.
Finde das Problem mit dem KI- Agent.

## AS6 - Project 'refactor'

In diesem Projekt sind viel zu viele C- Funktionen innerhalb einer Datei untergebracht.
Lassen den KI- Agenten für dich arbeiten und unterteile in mehrere C- Dateien.
